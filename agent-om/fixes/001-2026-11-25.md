### C-2 A helper that tells whether a link is the page shown

- **Status:** checked
- **Fixes:** none on its own: C-3 to C-6 use it.
- **Where:** `src/components/hooks/useNavigation.ts` (it already returns `pathname`, `query`)
- **Change:** add to what the hook returns:
  ```ts
  const isCurrentHref = (href: string) => {
    const url = new URL(href, window.location.href);
    const here = new URLSearchParams(window.location.search);
    const there = url.searchParams;
    return (
      url.pathname === pathname &&
      [...there.keys()].length === [...here.keys()].length &&
      [...there.entries()].every(([k, v]) => here.get(k) === v)
    );
  };
  ```
  The address must match exactly, query included (guidelines 1.4): on `/websites/{id}?view=path` the nav's Overview is the
  section (`true`), the expanded view's Path the page.
- **Nothing visible changes:** a function; nothing renders.
- **Check:** with C-3 to C-6.
- **Outcome:** checked: the helper reads `useSearchParams()` instead of `window.location` (the plan's version reads `window` during render, which breaks the server render of every page that uses it). Behaviour as planned: /websites → `current="page"`, ?view=path → Overview `current="true"`, the expanded view's Path `current="page"`.
